## 📚 必须掌握的工具箱

### Redis工具箱
| 工具 | 功能 | 性能 | 适用场景 |
|------|------|------|---------|
| String + SETNX | 分布式锁 | 快 | 跨服务器互斥 |
| String + GET/SET | 缓存 | 极快 | 热点数据缓存 |
| Set | 去重、交集 | 快 | 点赞、关注 |
| ZSet | 排序 | 快 | 排行榜 |
| BitMap | 统计 | 快 | 签到 |
| GEO | 地理位置 | 快 | 附近的人 |

### 并发控制工具箱
| 工具 | 功能 | 适用场景 |
|------|------|---------|
| synchronized | 单机锁 | 单体应用 |
| Redis SETNX | 分布式锁 | 微服务 |
| 乐观锁 | 防超卖 | 库存扣减 |
| 悲观锁 | 强一致性 | 金融交易 |

### 缓存问题工具箱
| 问题 | 解决方案 |
|------|---------|
| 缓存穿透 | 缓存空值/布隆过滤器 |
| 缓存击穿 | 互斥锁/逻辑过期 |
| 缓存雪崩 | 随机TTL |

### 学习原则
1. **停止学新东西，先把基础补上**
   - 不要再看新的技术文章
   - 不要再学新的框架
   - 专注于调试技能

2. **实践>理论**
   - 每天必须写代码/调试
   - 不能只看不练
   - 理解了要验证

3. **记录>记忆**
   - 遇到的问题记录下来
   - 解决方案记录下来
