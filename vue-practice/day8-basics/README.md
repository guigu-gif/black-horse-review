# Day 8 - Vue基础：数据绑定

## 学习目标
理解Vue的核心思想：**数据驱动视图**

## 文件说明

### 01-traditional.html - 传统做法
- 手动获取DOM元素（`getElementById`）
- 手动监听事件（`addEventListener`）
- 手动更新页面（`textContent = ...`）

**代码量：** 需要写DOM操作代码

### 02-vue-version.html - Vue做法
- 用 `v-model` 双向绑定数据
- 用 `{{ }}` 显示数据
- **不需要任何DOM操作代码**

**代码量：** 只需要定义数据

## 如何运行
直接用浏览器打开这两个HTML文件，对比效果。

## 核心概念

### v-model
双向数据绑定：
- 输入框的值变 → 数据自动变
- 数据变 → 输入框的值自动变

### {{ message }}
插值表达式：直接在HTML里显示数据

## 对比总结

| | 传统做法 | Vue做法 |
|--|---------|---------|
| 思维方式 | 操作DOM | 操作数据 |
| 代码量 | 多 | 少 |
| 维护性 | 复杂后很乱 | 结构清晰 |
